Player ID na prática — registrar partidas

Card ID ≠ Player ID. O Card ID identifica a edição da carta. O Player ID, animações e responsividade exigem observação da jogabilidade. Não existem números oficiais de animação garantidos nesta auditoria.

Registre partidas equivalentes (mesmo técnico, formação e faixa de adversário), alterando um jogador de cada vez. Estas notas são avaliações suas, não telemetria automática.

Backup e fontes

Os dados pessoais e partidas são salvos neste dispositivo, com as chaves scoutpro:, incluídas na opção Meus dados da barra inferior. Use Exportar no Windows e Importar no Android para transferir as observações; não há sincronização automática entre dispositivos.

Fontes: Konami — mudanças de movimento na v6.0.0 · PESDB 2027 — banco de dados independente. A presença de um registro no PESDB não garante que a edição física no seu aparelho esteja idêntica após atualizações.
